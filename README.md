#  Processo de Empréstimo de Livros

Este projeto tem como objetivo desenvolver um sistema para **controlar o empréstimo de livros da biblioteca da Escola São Bernardo (ESB)**, principalmente para os alunos dos cursos técnicos de Enfermagem e Farmácia.

Atualmente, o empréstimo é realizado manualmente. O aluno apresenta sua identificação e solicita o material desejado. O responsável verifica se o livro está disponível, registra o empréstimo e informa o prazo para devolução.

A proposta é transformar esse processo em um **sistema digital**, facilitando o trabalho do atendente e reduzindo possíveis erros nos registros.

## Como funcionará

O aluno apresenta sua identificação e informa qual livro deseja emprestar. O atendente consulta o aluno e o livro no sistema e registra o empréstimo.

Após o registro, o sistema **define automaticamente a data de devolução** e permite acompanhar quais livros estão:

* Disponíveis;
* Emprestados;
* Devolvidos;
* Em atraso.

Dessa forma, o sistema busca tornar o processo de empréstimo **mais rápido, organizado e confiável**, facilitando o controle dos materiais da biblioteca e o acompanhamento dos empréstimos.
